# بوت تتبع أفضل العروض (تليجرام)

بوت يتابع منتج تحدده وله ويبحث كل فترة في أمازون السعودية، نون، وإكسترا، ويبعثلك تنبيه في تليجرام أول ما يلقى أفضل سعر (أو سعر أقل من اللي قبله).

يشتغل مجاناً 100% عن طريق **GitHub Actions** (بدون سيرفر أو استضافة).

---

## 1) اعمل بوت تليجرام

1. افتح تليجرام وابحث عن **BotFather**.
2. ابعثله `/newbot` واتبع الخطوات (اسم + username ينتهي بـ bot).
3. بيعطيك **Token** يشبه: `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — احفظه.

## 2) اعرف الـ Chat ID تبعك

1. ابعث أي رسالة للبوت اللي سويته (مثلاً "هلا").
2. افتح هذا الرابط في المتصفح (بدّل TOKEN بالتوكن تبعك):
   `https://api.telegram.org/botTOKEN/getUpdates`
3. بتلقى JSON فيه `"chat":{"id": 123456789 ...}` — هذا الرقم هو الـ Chat ID.

## 3) ارفع الملفات على GitHub

1. سوّي ريبو جديد على GitHub (خليه **Private** أفضل).
2. ارفع كل الملفات اللي بهذا المجلد بنفس البنية (لازم مجلد `.github/workflows/` يضل بمكانه).

## 4) ضيف الأسرار (Secrets)

داخل الريبو: **Settings → Secrets and variables → Actions → New repository secret**

- `TELEGRAM_BOT_TOKEN` = التوكن من الخطوة 1
- `TELEGRAM_CHAT_ID` = الرقم من الخطوة 2

## 5) شغّله

- روح تبويب **Actions** بالريبو، لازم تلقى workflow اسمه "Check Deals".
- شغّله يدوياً أول مرة (زر Run workflow) عشان تتأكد إنه يشتغل صح.
- بعدين بيشتغل تلقائياً كل 30 دقيقة (تقدر تغيّر التوقيت من ملف
  `.github/workflows/check-deals.yml`، السطر اللي فيه `cron`).

## 6) استخدمه

- ابعث اسم أي منتج للبوت في تليجرام (مثلاً: "ايفون 16 برو 256 جيجا") → بيبدأ يتابعه.
- `قائمة` → يعرض المنتجات المتابَعة وأفضل سعر لقاه لكل وحدة.
- `حذف [رقم]` → يشيل منتج من المتابعة (شوف رقمه من "قائمة" أول).

⚠️ الأوامر ما ترد عليها فوراً — لازم تنتظر لين يشتغل الـ workflow التالي (كل 30 دقيقة كحد أقصى).

---

## ملاحظات مهمة

- **السكرابنق مو API رسمي**: البوت يقرأ صفحة نتائج البحث بنفس طريقة المتصفح.
  المواقع (خصوصاً نون اللي يعتمد على JavaScript بشكل كبير) ممكن تغيّر تصميم
  الصفحة، فإذا صار متجر معين ما يرجع نتائج، افتح صفحة البحث بالمتصفح، اعمل
  Right Click → Inspect على السعر والعنوان، وحدّث الـ CSS selectors في دالة
  المتجر داخل `bot.py` (كل متجر له دالة منفصلة بنفس الاسم).
- استخدمه لأغراض شخصية فقط — بعض المواقع شروط استخدامها تمنع السكرابنق الآلي
  بشكل صريح، فهذا على مسؤوليتك.
- GitHub Actions مجاني للريبو الخاص (Private) لين 2000 دقيقة بالشهر — تشغيل
  كل 30 دقيقة يستهلك جزء بسيط منها ومايقارب الحد.
- التنبيه يصير بس لما يلقى سعر **أقل** من أفضل سعر مسجل له سابقاً (أو أول
  نتيجة يلقاها للمنتج). لو تبي تنبيه بكل تشغيلة بغض النظر عن التغيّر، قولي
  وأعدل المنطق.
